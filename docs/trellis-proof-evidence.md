# Trellis proof evidence

The Trellis profile validates typed source, proof-IR, verifier receipt,
assumption, property, requirement, and span links. Reference-only, formal-proof
candidate, and policy-accepted formal-proof outcomes remain distinct; a passed
receipt alone cannot promote a candidate. Graph rows preserve scoped
traceability. Validation does not prove verifier soundness, downstream system
correctness, requirement satisfaction, or release eligibility.
