# Proof-carrying IR lineage

Valence records source/IR references, node and proof-obligation identifiers,
transform steps, opaque dialect identity, payload hashes, proof-sidecar links,
roles, and non-claims. Unknown dialects remain recorded-only and uninterpreted.
Producers or CLI shells own format parsing and checker execution. Passing this
profile proves identity/linkage conformance only, not source-to-IR correctness,
proof discharge, solver soundness, compiler/codegen correctness, semantic
equivalence, or release eligibility.
